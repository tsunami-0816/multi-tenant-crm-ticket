## 三、踩坑记录（给下次迭代）

1. **conftest register 重复用户**：AuthService.register 没做 username 唯一检查，导致 selectOne 报错。修法：conftest 直接 login，依赖预置账号。
2. **布隆过滤器未预热**：create() 后新 ID 不在 bloom，getById 直接返回 null。修法：create() 后 bloom.add(id)。
3. **ObjectMapper 缺 JSR310**：手动 new ObjectMapper 序列化 LocalDateTime 报错。修法：.registerModule(new JavaTimeModule())。
4. **Nacos OOM**：16GB 机器跑 rag-* 容器后 Nacos 启动就 exit 137。修法：本地禁用服务发现，gateway 静态路由直连。
5. **Kafka 镜像 403**：apache/kafka:3.6.1 镜像源 403。修法：换 bitnami/kafka:3.6。
6. **Vite proxy 兼容问题**：Vite proxy 调 gateway 报 Parse Error。修法：前端 baseURL 直连 gateway:8080。
