# step06 本地冒烟记录

> 日期：2026-10-27
> 执行人：Agent（用户授权自主推进）

## 验证环境

- 本地直跑：gateway(8080) + customer(8081) + ticket(8082)
- 基础设施 Docker：MySQL 8.0(3306)、Redis 7.2(宿主机6380)、Kafka bitnami 3.6(9092)
- Nacos：OOM 不可用，gateway 改静态路由，禁用服务发现

## 通过项

1. 注册租户 tenantId=1, userId=1
2. 登录签发 JWT
3. 无 token 访问 401（gateway 鉴权）
4. 建客户 tenant_id/created_by 自动填充
5. 客户列表多租户隔离（只返回 tenant_id=1）
6. 建工单 status=OPEN
7. OPEN->PROCESSING->RESOLVED 正常流转
8. RESOLVED->OPEN 非法流转 40901 拒绝
9. Kafka 端到端 TICKET_CREATED 写入 customer_timeline
10. MySQL 7 张表 / Redis Redisson 24 连接

## 修过的坑

1. MySQL init.sql 挂载路径 ./sql/ -> ./backend/sql/
2. apache/kafka 403 -> bitnami/kafka:3.6
3. Nacos OOM -> 禁用服务发现，静态路由
4. jjwt-impl/jackson 版本 / Lombok / UTF-8 / LongValue / -parameters 编译标志
5. customer_timeline 加入多租户 ignoreTable（Kafka 线程无 HTTP 上下文）
